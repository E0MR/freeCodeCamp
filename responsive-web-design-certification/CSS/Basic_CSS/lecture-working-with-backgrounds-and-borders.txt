2] What Is a Background Gradient, and How Does It Work?

    # Questions

        1) What does the circle keyword specify in a radial-gradient() function?

            The gradient will have a square shape.

            The gradient will extend in a diagonal direction.

            The gradient will have a circular shape.
            Correct!

            The gradient will be applied to the text.


        2) What does the farthest-corner keyword do in the size parameter of a radial-gradient() function?

            It makes the gradient extend to the nearest corner of the element.

            It makes the gradient cover the entire element's width.

            It makes the gradient extend to the farthest corner of the element.
            Correct!

            It makes the gradient only appear within the element's padding.


        3) In the radial-gradient(circle at center, red, yellow 50%, green) function, where is the gradient's center located?

            At the top right corner of the element.

            At the bottom left corner of the element.

            At the center of the element.
            Correct!

            At the outer edge of the element.

        2) Which of the following should be avoided when placing text over a background?

        3) What is the issue with using color as the only indicator of information, such as showing an error message in red?

4] What Are the Different Ways You Can Add Borders Around Images?

    # Questions

        1) Which CSS property allows you to create a border that doesn't affect the element's dimensions?

            border

            outline
            Correct!

            box-shadow

            border-image


        2) How would you create a 3-pixel wide, dashed, red border only on the left side of an image?

            img {
                border: 3px dashed red left;
            }

            img {
                border-left: 3px dashed red;
            }
            Correct!

            img {
                left-border: 3px dashed red;
            }

            img {
                border: left 3px dashed red;
            }


        3) Which CSS property would you use to round the corners of a border?

            border-style

            border-radius
            Correct!

            border-spacing

            border-bottom
