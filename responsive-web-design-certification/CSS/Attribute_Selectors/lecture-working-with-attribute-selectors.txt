1] What Is the Attribute Selector, and How Can It Be Used to Target Links with the href and title Attributes?

    # Questions

        1) Which CSS selector would you use to target all links with an href attribute?

            a[href]
            Correct!

            a[href=""]

            a[href="https"]

            a[href*="https"]


        2) What does the attribute selector do in CSS?

            It targets elements based on their tag name.

            It targets elements based on their class name.

            It targets elements based on their attributes.
            Correct!

            It targets elements based on their ID.

        3) Which of the following CSS rules will style links with both href and title attributes?

            a[href]

            a[title]

            a[href][title]
            Correct!

            a[href*="title"]



2] How to Use the Attribute Selector to Target Elements with the lang and data-lang Attributes?

    # Questions

        1) Which CSS selector would you use to target all paragraphs where the lang attribute is set to English?

            p[lang="en"]
            Correct!

            p[lang]

            p[lang="es"]

            p[lang*="en"]


        2) How would you target all div elements that have a data-lang attribute set to fr?

            div[data-lang]

            div[data-lang="fr"]
            Correct!

            div[lang="fr"]

            div[data-lang*="fr"]


        3) Which attribute would you use in HTML to specify the language of the content inside an element?

            data-lang

            class

            lang
            Correct!

            id



3] How to Use the Attribute Selector to Target Ordered List Elements with the type Attribute?

    # Questions

        1) Which CSS selector would you use to target ordered lists that use uppercase alphabetical numbering?

            ol[type="A"]
            Correct!

            ol[type="a"]

            ol[type="1"]

            ol[type="I"]


        2) How would you target ordered lists that use lowercase Roman numerals?

            ol[type="I"]

            ol[type="1"]

            ol[type="i"]
            Correct!

            ol[type="A"]


        3) Which attribute is commonly used in HTML to specify the numbering style of an ordered list?

            data-type

            type
            Correct!

            style

            order
